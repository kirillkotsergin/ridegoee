## 1. Что это за проект

`ridego.ee` — одностраничный сайт (лендинг) услуги **трансфера из Таллинна
к погранпереходам с Россией**: Нарва, Койдула, Лухамаа.

- Язык сайта: **русский** (`<html lang="ru">`), тексты и комментарии в коде тоже на русском.
- Аудитория: пассажиры, которым нужно доехать до пункта пропуска на границе.
- Конверсия: не форма, а **переход в WhatsApp / Telegram / звонок** по номеру
  **+372 5627 7764**.

## 2. Стек и принципы

| | |
|---|---|
| Тип | статический сайт, **без сборки** — ни npm, ни бандлера, ни фреймворка |
| Код | чистые HTML + CSS + ES5-совместимый JS в IIFE (`"use strict"`) |
| Зависимости | **ноль**. Внешних шрифтов и CDN тоже нет — шрифт системный (`system-ui`) |
| Просмотр локально | открыть `public/index.html` в браузере, либо `npx serve public` |
| Пути к ассетам | **относительные** (`styles.css`, `favicon.svg`), чтобы страница работала и с диска |

Важные правила, заложенные в код:

- Тёмная тема, палитра в `:root` файла `public/styles.css`
  (`--bg: #080b12`, `--accent: #ffb524`, `--wa: #25d366`, `--tg: #2aabee`).
- Анимации появления включаются **только если работает JS**: в `<head>` ставится
  класс `js` на `<html>`, и CSS скрывает `.reveal` лишь при наличии этого класса.
  Без JS контент виден целиком.
- Есть блок `@media (prefers-reduced-motion: reduce)` — анимации отключаются.
- В hero едет **фото** машины: `.drive` — полоса с `overflow: hidden`, внутри
  `.drive__car` с анимацией `drive`. Скорость и размер — переменные `--drive-time`
  и `--drive-size` у `.drive`. Меняешь `--drive-size` — поправь `139%` в `@keyframes
  drive` (проценты там от ширины самой машины) и `19%` в блоке reduced-motion.
  Прежней векторной машины (`.car`, `.wheel`, `.road`) больше нет.
- Доступность: `skip-link`, `aria-label` на иконках, `aria-hidden` на декоре,
  возврат фокуса на кнопку после закрытия модалки.

### Как работает заказ

Любая кнопка с атрибутом `data-order` открывает `<dialog>` через делегирование
клика на `document`. Если у кнопки есть `data-route="Таллинн — Нарва"`, в ссылку
WhatsApp подставляется готовый текст сообщения. `PHONE = "37256277764"` задан
константой в начале `public/script.js` — при смене номера править и там, и в HTML
(номер встречается в нескольких местах: шапка, hero, CTA, подвал, модалка).

Telegram-ссылка сделана по номеру: `https://t.me/+37256277764` — если у аккаунта
появится короткое имя, надёжнее заменить на `https://t.me/имя`.

## 4. Деплой

`git push` в `main` → GitHub Actions → `rsync -rlvz --delete public/ → htdocs/` по SSH
на zone.ee. Ручной запуск доступен через `workflow_dispatch` во вкладке Actions.

- `--delete` значит: **хостинг = точная копия `public/`**. Чего нет в репозитории —
  на сервере удаляется. Исключения: `.well-known/` и `.git*`.
- ⚠️ **Ловушка, на которую уже наступили.** 12.08 в 21:01 кто-то перезапустил run #1
  во вкладке Actions. Он выложил `public/` из `origin/main`, где лежит только старая
  эстонская заглушка на 340 байт, и `--delete` снёс весь залитый вручную сайт вместе
  с `.htaccess`. Вывод: **пока `main` не запушен, любой запуск деплоя откатывает
  сайт к заглушке.** Ручная заливка — только как временная мера.
- Секреты в GitHub: `ZONE_SSH_PRIVATE_KEY`, `ZONE_SSH_USER`, `ZONE_SSH_HOST`,
  `ZONE_REMOTE_PATH`. Порт по умолчанию 22.
- Реквизиты хостинга (пользователь, хост, DocumentRoot, IP) — в README.md, раздел
  «Данные хостинга».
- Репозиторий **публичный** (`github.com/kirillkotsergin/ridegoee`), поэтому README
  с реквизитами хостинга виден всем.

### Zone API v2

Управление доменом и хостингом доступно через API, это спасает, когда в панели
чего-то не найти. База — `https://api.zone.eu/v2`, авторизация HTTP Basic
`логин_ZoneID:токен` (логин `kirja777`; токен создаётся в ZoneID → Настройки
аккаунта → Безопасность → API-ключи).

| Что | Эндпоинт |
|---|---|
| Сервер целиком | `GET /vserver/ridego.ee` (пакет Starter, `alias_limit` 50, `cron_limit` 2) |
| Хост и его сертификат | `GET,PUT /vserver/ridego.ee/host/ridego.ee` |
| Сертификаты | `GET,POST,DELETE /vserver/ridego.ee/ssl` — POST требует `name`, `private_key`, `certificate` |
| Cron | `GET,POST,PUT,DELETE /vserver/ridego.ee/crontab` — `type` только `system`, `report` — `never`/`always`/`onerror` |
| DNS-записи | `GET,POST /dns/ridego.ee/a` и так же `aaaa`, `mx`, `txt`, `cname`, `caa` |

Бесплатный Let's Encrypt от Zone через API **не заказывается** — у хоста есть только
поле `letsencrypt_status` (было `waiting`), запустить его извне нельзя. Поэтому
сертификат выпускаем сами (см. ниже).

### Сертификат и автопродление

- Выпущен `acme.sh` v3.1.5 (стоит в `~/.acme.sh`) через **DNS-01** провайдером
  `dns_zone` — он сам создаёт TXT-записи через тот же Zone API.
  HTTP-01 не годится: каталог `.well-known/acme-challenge/` перехватывает сам Zone,
  файлы из `htdocs` там не отдаются.
- Установлен на хостинг через `POST /ssl` + `PUT /host` (`certificate=221513`).
  Рядом лежит `221512` — сертификат, который Zone выпустил сам, только на apex;
  оставлен как страховка, но не привязан.
- Автопродление: cron `id=27270`, `11 1,7,13,19 * * *` UTC, `report=onerror`
  (письмо на kirill.kotsergin@gmail.com только при сбое), запускает
  `~/.acme.sh/renew-and-install.sh`. Обёртка продлевает, ставит новый сертификат
  через API (идемпотентно — сравнивает отпечаток с установленным), проверяет, что
  живой сертификат на `:443` действует ещё минимум 20 дней, и возвращает не 0 при
  любой беде. Лог — `~/.acme.sh/renew.log`.
- ⚠️ **API-токен Zone лежит на сервере** в `~/.acme.sh/account.conf` (права 600,
  каталог 700) — от него зависит автопродление. **Отзовёшь токен — продление умрёт**,
  и 10.11.2026 сайт останется без сертификата.

## 7. Договорённости по работе

- Все пользовательские тексты и комментарии в коде — **на русском**.
- Не добавлять сборку, npm-зависимости и внешние CDN без явной просьбы: ценность
  проекта в том, что он открывается как обычные файлы.
- Всё, что должно попасть на сайт, кладём в `public/` — остальное на хостинг не уедет.
- Ключи и приватные данные в репозиторий не коммитим (см. `.gitignore`).
- `tools/make-icons.ps1` должен лежать в **UTF-8 с BOM** — Windows PowerShell 5.1 иначе
  читает русские строки как мусор и падает на парсинге.
- Растровые иконки и `og.png` не правим руками: меняем скрипт и перегенерируем.
- JSON-LD в конце `index.html` держим в согласии с ценами и ответами FAQ на странице.
- Этот файл обновляем при изменениях структуры, стека, деплоя или списка задач.
